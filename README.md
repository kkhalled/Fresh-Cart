## 🚀 Overview

FreshCart is a modern, full-featured e-commerce platform built with Next.js, React, and TypeScript. It offers a seamless shopping experience with robust authentication, product browsing, cart management, and secure checkout. Designed for scalability and performance, FreshCart leverages the latest technologies and best practices in frontend development.

## ✨ Features

- **User Authentication**: Sign up, sign in, password reset, and secure session management.
- **Product Catalog**: Browse products by categories, view detailed product pages, and search functionality.
- **Shopping Cart**: Add, update, and remove items from your cart with real-time updates.
- **Wishlist**: Save favorite products for later.
- **Checkout Process**: Streamlined and secure checkout with order summary.
- **Account Management**: Manage user profile and view order history.
- **Responsive Design**: Fully responsive UI for mobile and desktop.
- **Notifications**: Real-time feedback using toast notifications.
- **Modern UI**: Clean, accessible, and visually appealing interface using Tailwind CSS.

## 🛠️ Tech Stack

- **Framework**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Redux Toolkit (client), TanStack React Query (server)
- **Forms & Validation**: React Hook Form, Zod
- **API Communication**: Axios
- **Icons**: Font Awesome
- **Notifications**: React Toastify

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/Fresh-Cart.git
   cd Fresh-Cart
   ```
2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view the app.

## 🔑 Environment Variables

Configure your API endpoints and secrets in a `.env.local` file as needed.

## 📁 Project Structure

- app — Main application pages (authentication, platform features)
- components — Shared and UI components (Navbar, Footer, FormInput, etc.)
- features — Feature modules (auth, cart, wishlist, etc.)
- store — Redux store configuration
- config — API endpoints and configuration
- styles — Global styles
